# AnonMail 📩

Simple Flask web app for sending anonymous emails via Gmail SMTP.

---

## 🔍 About

AnonMail is a minimal web app built with Flask that lets users send emails anonymously using Gmail SMTP. The app provides a simple web form to enter the recipient email and message, and shows success ✅ or error ❌ messages after sending.

---

## ⚙️ Features

- Web form to input recipient email + message  
- Uses Gmail SMTP to deliver the message  
- Shows success ✅ or error ❌ feedback in the browser  

---

## 🚀 Setup & Run

Follow these steps to run the app:

## 1. Clone the repository:
```bash
   git clone https://github.com/Atog-hub/AnonMail.git
```
## 2. Navigate into the project folder:
```bash
   cd AnonMail
```
## 3. Install Flask if you don't already have it:
```bash
   pip install flask
```
## 4. Run the app:
```bash
   python app.py
```
